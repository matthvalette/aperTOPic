# OpenParlData Topic Classification & RAG with Apertus

An open-source classification service for Swiss parliamentary data powered by **Apertus v1.5** and the **OpenParlData API**.

## Features
- **Multilingual Support**: Handles DE, FR, IT, and RM natively.
- **Zero-Shot / Ad-Hoc Topics**: Classify affairs into standard (APS) or user-defined topics without retraining.
- **Explainability & Transparency**: Provides exact passage evidence and neutral rationale.
- **FastAPI + Streamlit Stack**: Easy integration and interactive demo interface.
